# SIAKAD SMK — Frontend

Frontend statis (HTML/CSS/JS murni, tanpa build) untuk GitHub Pages. Backend: Google Apps Script REST API (`Kode.gs`, terpisah).

Isi `js/config.js` dengan URL Web App `/exec`, lalu ikuti **PANDUAN-INSTALASI.md**.

Struktur: `index.html` · `css/style.css` · `js/{config,api,ui,app,pages-a,pages-b}.js`
